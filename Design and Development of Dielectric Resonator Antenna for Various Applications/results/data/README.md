# Data

- `results_summary.json`: all headline numbers from the paper (Tables II-III) plus the preliminary VNA values. Tests in `tests/test_results_data.py` check it for internal consistency (VSWR vs S11, bandwidth vs band edges).
- `comparison_table.md`: generated by `python -m analysis.compare_results`.

## Adding raw curves

Export from HFSS: *Results → right-click a plot → Export Data*, as CSV, two columns (`Freq [GHz]`, value). Suggested names:

```
zirconia_cdra_s11_hfss.csv
alumina_cdra_s11_hfss.csv
circular_patch_s11_hfss.csv
```

VNA data go in `results/measurements/` as `.s1p`.
